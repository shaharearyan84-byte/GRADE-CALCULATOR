# GRADE-CALCULATOR
# 🎓 Grade Calculator using Streamlit

A simple and interactive Grade Calculator built with Python and Streamlit in VS Code. This application allows students to enter their marks, calculate percentages, and determine their grades instantly through a user-friendly web interface.

## 🚀 Features

- Calculate percentage based on marks entered
- Automatic grade assignment
- Clean and attractive user interface
- Real-time calculation
- Built using Streamlit and Python
- Beginner-friendly project

## 🛠️ Technologies Used

- Python
- Streamlit
- VS Code

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Grade-Calculator.git
```

2. Navigate to the project folder

```bash
cd Grade-Calculator
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
streamlit run app.py
```
